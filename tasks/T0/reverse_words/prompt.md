# Reverse Words

Write a function `reverse_words(s: str) -> str` that reverses the order of words in a string.

Words are separated by whitespace. Multiple spaces between words should be collapsed to a single space in the output. Leading and trailing whitespace should be removed.

## Examples

```python
reverse_words("hello world") == "world hello"
reverse_words("  the sky is blue  ") == "blue is sky the"
reverse_words("one") == "one"
reverse_words("") == ""
```
