# Remove Duplicates

Write a function `remove_duplicates(lst: list) -> list` that removes duplicate elements from a list while preserving the original order.

Only the first occurrence of each element should be kept.

## Examples

```python
remove_duplicates([1, 2, 3, 2, 1]) == [1, 2, 3]
remove_duplicates([1, 1, 1]) == [1]
remove_duplicates([]) == []
remove_duplicates(["a", "b", "a", "c"]) == ["a", "b", "c"]
```
