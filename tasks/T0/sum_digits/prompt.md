# Sum Digits

Write a function `sum_digits(s: str) -> int` that sums all the digits found in a string.

Non-digit characters should be ignored. If there are no digits, return 0.

## Examples

```python
sum_digits("abc123") == 6  # 1 + 2 + 3
sum_digits("hello") == 0
sum_digits("1a2b3c") == 6
sum_digits("99") == 18  # 9 + 9
```
