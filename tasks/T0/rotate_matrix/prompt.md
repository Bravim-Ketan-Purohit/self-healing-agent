# Rotate Matrix

Write a function `rotate_matrix(matrix: list[list[int]]) -> list[list[int]]` that rotates an NxN matrix 90 degrees clockwise.

- Return a new matrix (do not modify the original).
- An empty matrix should return an empty list.

## Examples

```python
rotate_matrix([[1, 2], [3, 4]]) == [[3, 1], [4, 2]]
rotate_matrix([[1, 2, 3], [4, 5, 6], [7, 8, 9]]) == [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
rotate_matrix([[1]]) == [[1]]
rotate_matrix([]) == []
```
